# sector17s（17業種マスタ）

## 概要

JPX（日本取引所グループ）が定める17業種分類のマスタテーブル

## データソース

- **API**: `/v2/equities/master` の `S17` / `S17Nm` フィールド
- **更新頻度**: ほぼ不変（数年に一度の改定があるかないか）
- **Layer**: Layer 1 (Raw Data - J-Quants API)

## スキーマ

| カラム | 型 | NULL | 説明 |
|--------|---|------|------|
| `id` | UUID | NOT NULL | 主キー |
| `sector17_code` | VARCHAR(10) | NOT NULL | 17業種コード（ビジネスキー） |
| `sector17_name` | VARCHAR(100) | NOT NULL | 17業種名 |
| `created_at` | TIMESTAMP | NOT NULL | 作成日時 |
| `updated_at` | TIMESTAMP | NOT NULL | 更新日時 |

## インデックス

- `ix_sector17s_sector17_code` (sector17_code) - UNIQUE

## 登録データ

**18種類**（17業種 + その他）

| sector17_code | sector17_name |
|--------------|--------------|
| 1 | 食品 |
| 2 | エネルギー資源 |
| 3 | 建設・資材 |
| 4 | 素材・化学 |
| 5 | 医薬品 |
| 6 | 自動車・輸送機 |
| 7 | 鉄鋼・非鉄 |
| 8 | 機械 |
| 9 | 電機・精密 |
| 10 | 情報通信・サービスその他 |
| 11 | 電気・ガス |
| 12 | 運輸・物流 |
| 13 | 商社・卸売 |
| 14 | 小売 |
| 15 | 銀行 |
| 16 | 金融（除く銀行） |
| 17 | 不動産 |
| 99 | その他 |
