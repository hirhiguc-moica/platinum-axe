# プロジェクト概要 - プラチナの斧

**最終更新**: 2026-07-21

---

## プロジェクト名

**プラチナの斧（platinum-axe）**

---

## コンセプト

> 「高度なクオンツ分析を個人投資家に無償公開し、投資判断の勝率向上に貢献する」

機械学習を活用した日本株銘柄推奨システム。J-Quants APIから取得した東証公式データと、LightGBM（勾配ブースティング）による高度な定量分析で、個人投資家の投資判断をサポートします。

---

## システムの目的

### 1. 個人投資家の投資環境改善

従来、機関投資家や富裕層のみがアクセスできた高度な定量分析（クオンツ分析）を、個人投資家にも無償提供し、情報格差を縮めます。

### 2. データ駆動型の投資判断支援

感情や直感ではなく、データに基づいた客観的な投資判断をサポートします。

### 3. 透明性の高い実績公開

推奨銘柄の実績を隠さず公開し、システムの信頼性を担保します。

---

## 核心機能

### 1. 週次ラウンド制

**ラウンド = 1週間の推奨サイクル**

毎週月曜日に、今週の推奨銘柄を公開:

- **買い推奨 Top 10**: 今週上昇が期待される銘柄
- **売り推奨 Top 10**: 今週下落が予想される銘柄（空売り推奨）

翌週月曜日に、前週の推奨銘柄の実績を検証・公開。

**週次サイクル**:

```
【月曜 9:00】ラウンドN開始
├─ 買い推奨 Top 10公開
└─ 売り推奨 Top 10公開

【月〜金】取引期間

【翌週月曜 9:00】ラウンドN終了・実績公開
├─ 買い推奨の勝率・平均リターン
└─ 売り推奨の勝率・平均リターン
```

### 2. デイリー強シグナル

毎営業日18:30〜19:00頃、特に強い売買シグナルが検出された銘柄を公開:

- **強い買いシグナル**: 予測騰落率 +5% 以上
- **強い売りシグナル**: 予測騰落率 -5% 以下
- **信頼度スコア**: 80% 以上

### 3. 機械学習による予測

**アルゴリズム**: LightGBM（Light Gradient Boosting Machine）

**予測ターゲット**: 翌週の騰落率（今週月曜終値 → 翌週金曜終値）

**特徴量**:
- ファンダメンタル: PER, PBR, ROE, 売上成長率等
- テクニカル: 移動平均, RSI, MACD, ボリンジャーバンド等
- 市場センチメント: 信用取引残高, 空売り比率等
- マクロ経済: TOPIX, 日経225, セクター騰落率等

## データソース

### J-Quants API

**提供元**: 株式会社J-Quants（日本取引所グループ関連）

**契約プラン**: Standardプラン（¥3,300/月）

**データ期間**: 過去10年分

**データ内容**:
- ✅ 株価四本値（OHLC、調整済み株価）
- ✅ 財務諸表（PL, BS, CF、四半期・通期）
- ✅ 配当・株式分割情報
- ✅ 信用取引残高（日々公表・週末残高）
- ✅ 空売り比率・残高
- ✅ 投資部門別売買動向
- ✅ 上場銘柄マスタ
- ✅ TOPIX・日経225データ

**更新タイミング**:
- **17:30頃**: 当日取引終了後、データ更新
- **翌営業日 8:00頃**: 追加データ更新・確定データ配信

## データベース設計

### 4層レイヤー構造

```
【Layer 1】Raw Data（トランザクションデータ）
  └─ J-Quants APIから取得した生データをそのまま保存
     - stock_prices_daily（株価四本値）
     - financial_statements（財務諸表）
     - margin_trading_daily（信用取引日次）
     - margin_trading_weekly（信用取引週次）
     - market_sentiment（空売り比率等）
     - stock_master（銘柄マスタ）
     - 等、全19テーブル

【Layer 2】Derived Data（計算済みデータ）
  └─ テクニカル指標を事前計算してDB保存
     - technical_indicators（MA, RSI, MACD, ボリンジャー等）

【Layer 3】Feature Store（機械学習用特徴量）
  └─ モデル学習・推論用に最適化されたデータ
     - ml_features（全特徴量をJSONB形式で保存）

【Layer 4】Prediction & Result（予測・結果）
  └─ ラウンド推奨・デイリーシグナル・実績データ
     - rounds（ラウンド管理）
     - round_recommendations（推奨銘柄）
     - round_results（結果検証）
     - daily_signals（デイリーシグナル）
```

**設計の利点**:
- 📝 **トランザクションデータ保存**: APIデータの履歴追跡可能
- 🔄 **再計算可能**: バグ修正時に過去データの再処理ができる
- ⚡ **高速推論**: テクニカル指標を事前計算（毎回計算不要）
- 📊 **監査可能**: データ品質チェック・可視化が容易

詳細: `docs/database/schemas.md`

## 機械学習モデル

### アルゴリズム

**LightGBM（Light Gradient Boosting Machine）**

- Microsoft社が開発した高性能な勾配ブースティング手法
- 高い予測精度と高速な学習・推論が特徴
- Kaggle等のデータ分析コンペティションで広く使われる手法

### 予測ターゲット

**翌週の騰落率**を回帰予測:

```
入力: 今週金曜時点のデータ
出力: 今週月曜終値 → 翌週金曜終値の騰落率（%）
```

### 特徴量設計

詳細: `docs/ml/features.md`

**主要な特徴量カテゴリ**:

1. **ファンダメンタル指標（〜50特徴量）**
   - バリュエーション: PER, PBR, PCFR, PSR, EV/EBITDA
   - 収益性: ROE, ROA, 営業利益率, 純利益率
   - 成長性: 売上高成長率, 利益成長率（YoY）
   - 健全性: 自己資本比率, 流動比率, D/Eレシオ
   - 配当: 配当利回り, 配当性向

2. **テクニカル指標（〜80特徴量）**
   - トレンド系: 移動平均（5, 20, 50, 75日）, MACD, ADX
   - オシレーター系: RSI, ストキャスティクス, CCI
   - ボラティリティ系: ボリンジャーバンド, ATR, 標準偏差
   - 出来高系: 出来高移動平均, OBV, 売買代金

3. **市場センチメント指標（〜30特徴量）**
   - 信用取引: 信用買い残高, 信用売り残高, 信用倍率
   - 空売り: 空売り比率, 空売り残高
   - 投資主体別: 外国人買い越し額, 個人買い越し額

4. **マクロ経済指標（〜20特徴量）**
   - 市場全体: TOPIX騰落率, 日経225騰落率
   - セクター: 所属セクターの騰落率
   - 相対パフォーマンス: TOPIXに対する相対リターン

### モデル学習・評価

**学習データ**: 過去10年分（約2500営業日）

**検証手法**:
- バックテスト: 過去データでの検証
- ウォークフォワード検証: 未来データでの検証
- クロスバリデーション: 時系列分割（TimeSeriesSplit）

**評価指標**:
- 勝率: 60%以上
- 平均リターン: TOPIX平均を上回る
- シャープレシオ: 1.0以上
- 最大ドローダウン: -20%以内

**再学習頻度**: 月次（毎月第1週末）
