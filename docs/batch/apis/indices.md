# 指数四本値（日次）API - J-Quants API仕様

## 概要

**エンドポイント**: `GET https://api.jquants.com/v2/indices/bars/daily`

**公式ドキュメント**:
- API仕様: https://jpx-jquants.com/ja/spec/idx-bars-daily
- 指数コード一覧: https://jpx-jquants.com/ja/spec/idx-bars-daily/indexcodes

**目的**: TOPIX、TOPIX-17（17業種別指数）などの日次四本値データを取得

**取得可能期間**: 2009年2月2日〜現在（Standardプラン）

**レート制限**: 60件/分（株価・財務APIとは独立）

---

## 必須パラメータ

`code`（指数コード）または`date`（日付）のいずれか一つが必須。

---

## クエリパラメータ

| パラメータ | 型 | 必須 | 説明 | 例 |
|-----------|---|------|------|-----|
| `code` | string | ○* | 指数コード（4桁16進数） | `0000` (TOPIX) |
| `date` | string | ○* | 単一日付（YYYY-MM-DD形式） | `2024-01-15` |
| `from` | string | - | 期間指定（開始日） | `2024-01-01` |
| `to` | string | - | 期間指定（終了日） | `2024-12-31` |
| `pagination_key` | string | - | 検索開始位置の指定 | - |

*`code`または`date`のいずれか一つが必須

---

## レスポンス形式

```json
{
  "data": [
    {
      "Date": "2023-12-01",
      "Code": "0028",
      "O": 1199.18,  // 始値
      "H": 1202.58,  // 高値
      "L": 1195.01,  // 安値
      "C": 1200.17   // 終値
    }
  ],
  "pagination_key": "value1.value2."
}
```

## 注意事項

1. **日経平均株価は提供されていません**
   - J-Quants APIではTOPIX関連指数のみ提供
   - 日経平均が必要な場合は別のデータソース（Yahoo Finance等）を使用

2. **一部の指数はPremiumプラン限定**
   - 上記18指数はStandardプランで取得可能

3. **終値のみの指数も存在**
   - 一部の指数は四本値（O/H/L/C）がすべて同じ値になる場合がある

4. **前営業日データで代替される日がある**
   - 例: 2020年10月1日など

## バッチ処理設計

### 全量取得（初回のみ）

**スクリプト**: `backend/jobs/collectors/fetch_sector_indices.py`

**取得方法**:
- 38指数を1つずつループ
- 各指数について `from=2009-02-02` 〜 現在まで取得
- レート制限対策: 各指数取得後に1秒待機（60件/分を回避）

**所要時間**: 約40分（38指数 × 約1分）

**データ量**: 約140,000件（38指数 × 約3,700営業日）

---

### 差分取得（日次実行）

**スクリプト**: `backend/jobs/collectors/fetch_daily_sector_indices.py`

**取得方法**:
- DBの最新日付を取得
- 最新日+1日から現在まで取得（バックフィル対応）
- 38指数を1日分ずつ取得

**実行タイミング**: 毎営業日17:30（株価・財務取得後）

**所要時間**: 約1分（38指数 × 1日分）

**データ量**: 約38件/日

## DBテーブル設計

### `sector_indices_daily`（セクター指数日次データ）

**目的**:
- 機械学習の特徴量として使用（生データ: O/H/L/C）
- フロントエンド表示用（計算済み騰落率のみ表示、生データは非表示）

**カラム**:

| カラム名 | 型 | 説明 | JPX利用規約 |
|---------|---|------|------------|
| `id` | UUID | 主キー | - |
| `index_code` | VARCHAR(4) | 指数コード（例: 0000, 0080） | - |
| `index_name` | VARCHAR(50) | 指数名（例: TOPIX, 食品） | - |
| `date` | DATE | 日付 | - |
| `open` | DECIMAL(10,2) | 始値 | ❌ FE表示不可（生データ） |
| `high` | DECIMAL(10,2) | 高値 | ❌ FE表示不可（生データ） |
| `low` | DECIMAL(10,2) | 安値 | ❌ FE表示不可（生データ） |
| `close` | DECIMAL(10,2) | 終値 | ❌ FE表示不可（生データ） |
| `change_rate_1d` | DECIMAL(10,4) | 前日比騰落率（%） | ✅ FE表示可（計算済み） |
| `change_rate_5d` | DECIMAL(10,4) | 5日前比騰落率（%） | ✅ FE表示可（計算済み） |
| `change_rate_20d` | DECIMAL(10,4) | 20日前比騰落率（%） | ✅ FE表示可（計算済み） |
| `change_rate_60d` | DECIMAL(10,4) | 60日前比騰落率（%） | ✅ FE表示可（計算済み） |
| `created_at` | TIMESTAMP | 作成日時 | - |
| `updated_at` | TIMESTAMP | 更新日時 | - |

**UNIQUE制約**: `(index_code, date)`

**インデックス**:
- `index_code`
- `date`
- `(index_code, date)` UNIQUE

**騰落率の計算式**:
```python
change_rate_1d = ((close - close_1d_ago) / close_1d_ago) * 100
change_rate_5d = ((close - close_5d_ago) / close_5d_ago) * 100
change_rate_20d = ((close - close_20d_ago) / close_20d_ago) * 100
change_rate_60d = ((close - close_60d_ago) / close_60d_ago) * 100
```

**NULL値の扱い**:
- 過去データが存在しない場合（取得開始から5日未満など）はNULL
